# Pika iOS Assignment

## Overview
This project implements the take-home assignment using SwiftUI and MVVM architecture.

## Tech Stack
- Swift
- SwiftUI
- MVVM Architecture

## How to Run
1. Open PiKa.xcodeproj in Xcode
2. Select a simulator
3. Run the project

## Architecture
The project follows MVVM separation:
- Views: UI layer
- ViewModels: State & logic
- Models: Data layer

## Notes
- Focused on clean UI implementation based on Figma
- Ensured responsive layout and reusable components
